# 0007 分析結果はデータのバージョンごとにキャッシュする

## 状況
分析は購入データ全体を読むため、画面を開くたびに実行すると無駄が大きい。一方で、データを変えた直後に古い結果が出るのも困る。

## 決めたこと
- 購入の追加・削除・取り込みのたびに、データのバージョン番号を1つ増やす（同じトランザクションで）。
- 分析結果は「種類＋バージョン」をキーにデータベースへ保存し、同じバージョンの間は再利用する。

## 検討した他の案
- **一定時間で期限切れにする**：変更直後に古い結果が見えるか、無駄な再計算が起きる。
- **Redisなどの外部キャッシュ**：部品が増える割に、この規模では利点がない。

## 受け入れたこと
- 1件変えるだけでも分析は全体をやり直す。1人分では数百ミリ秒なので許容する。
