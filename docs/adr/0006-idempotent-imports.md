# 0006 取り込みは何度やり直しても同じ結果になるようにする

## 状況
利用者は同じファイルをうっかり2回取り込んだり、期間の重なるファイルを取り込んだりする。そのたびに合計が2倍になっては、分析が信用できない。

## 決めたこと
- お店・日時・商品名・金額・数量から1つのキーを作り、データベースの一意制約で重複を弾く。
- ファイル1つを1つのトランザクションで保存する。途中で失敗したら1件も残らない。
- 読めない行は行番号つきで知らせ、読める行だけを取り込む。

## 検討した他の案
- **画面側で重複を確認**：同時に2回送られると防げない。最終的な保証はデータベースに置く。

## 受け入れたこと
- 同じ日時・同じ商品・同じ金額の「本当に別の購入」は1件にまとまる。数量の列で区別できる場合はそちらを使ってもらう。
