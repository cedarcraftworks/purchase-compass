# 0003 2言語のやり取りを契約テストで守る

## 状況
Python側で項目名を変えてTypeScript側を直し忘れると、型チェックでは見つからない。本番の画面で初めて壊れる。

## 決めたこと
1. Pythonのテストが、分析サービスの実際の応答とAPI仕様書（OpenAPI）を `contract/` に書き出す。
2. TypeScriptのテストが、それを本番と同じzodスキーマで検証する。
3. CIでは毎回1→2の順に実行する。
4. 本番でもAPIは分析サービスの応答を毎回検証し、合わなければ壊れたデータを表示せず `502` を返す。

## 検討した他の案
- **OpenAPIからTypeScriptの型を自動生成**：型は一致するが、生成のための道具が増え、実行時の検証にはならない。
- **手作業で揃える**：人が忘れたら終わり。

## 受け入れたこと
- 項目を変えるときは、`UPDATE_CONTRACT=1 pytest` で記録を作り直す手順が1つ増える。
