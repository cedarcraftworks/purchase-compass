# 0008 公開デモはサーバー不要の静的版にし、取り込み処理を共有する

## 状況
面接官にはクリックだけで触れてもらいたい。しかしAPI・分析・DBの3つを常時公開するには、ホスティングの登録と費用・管理が必要になる。

## 決めたこと
- 公開デモは、本物のAPIの応答を記録したJSONを読む静的版にし、GitHub Pagesに置く。
- 書き込みはAPIのデモモードと同じく断る。
- 取り込みのプレビューは純粋な関数なので、取り込み処理を `packages/shared` に移し、APIと画面で同じコードを動かす。
- 静的デモでも、見本CSVの読み取りまで試せる。
- 記録したJSONが共有スキーマに合っているかは、webのテストで確かめる。

## 検討した他の案
- **フル構成を無料枠のホスティングに常駐させる**：手元の構成と同じで説得力はあるが、スリープからの復帰待ちや、アカウント管理が必要になる。手順は [docs/deploy.md](../deploy.md) に残してある。

## 受け入れたこと
- 公開デモでは保存ができず、分析結果は記録した時点のもので固定される。
