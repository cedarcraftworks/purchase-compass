# 0002 データベースを持つのはAPIだけにし、分析サービスは状態を持たない

## 状況
2つのサービスが同じデータベースを読み書きすると、表の形を変えるたびに両方を同時に直す必要があり、どちらが原因の不具合かも分かりにくくなる。

## 決めたこと
- データベースに触れるのはTypeScriptのAPIだけにする。
- 分析サービスは「購入の一覧を受け取り、結果を返す」だけで、何も保存しない。

## 検討した他の案
- **分析サービスもDBを直接読む**：大量データでは速いが、表の変更が2言語に波及する。

## 受け入れたこと
- 分析のたびに購入データを丸ごと送る。1人分（数千件まで）なら数百KBで問題ないが、大規模化すれば送り方を変える必要がある。
- 引き換えに、分析サービスは再起動・入れ替え・台数追加が自由で、移行作業も要らない。
