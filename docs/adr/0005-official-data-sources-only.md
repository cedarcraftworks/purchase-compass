# 0005 購入履歴と商品は公式に取れる方法だけで集める

## 状況
- Amazonには公式の注文履歴の出力があるが、楽天・メルカリには見当たらない。
- 商品を取得するAPIは、楽天にはあるが、Amazonは利用条件（継続的な売上実績）が厳しく、メルカリには一般向けがない。

## 決めたこと
- **購入履歴**：Amazonは公式の出力を自動で認識する。それ以外は、表の貼り付けかCSVを受け付け、列の対応は画面で確認・修正してもらう。
- **商品**：楽天は公式の商品検索APIを使う。Amazon・メルカリは検索ページへのリンクを表示する。
- 商品の取得元は1つの小さな部品（`ProductSource`）の裏に隠し、追加はクラス1つで済むようにする。

## 検討した他の案
- **スクレイピング**：利用規約に触れる恐れがあり、ページの変更ですぐ壊れる。
- **購入履歴を出す非公式のブラウザ拡張に頼る**：お店のログイン情報を扱うため、安全面で勧められない。

## 受け入れたこと
- 楽天・メルカリの取り込みは、利用者のひと手間（表のコピー）が残る。
